# Greg's Mobile Dent Repair

High-converting website replica and mobile-first landing experience for Greg's Mobile Dent Repair, providing expert paintless dent removal (PDR) across Mesa, Gilbert, Chandler, Tempe, Scottsdale, Queen Creek, Apache Junction, and Phoenix, Arizona.

## Features
- **Authentic Design Replica:** Styled 1:1 with the original brand purple (`#322878`) and orange (`#FFA500`) color palette.
- **Typography:** Rubik headings and Poppins body copy.
- **Interactive Elements:**
  - Elementor wave-brush SVG shape dividers.
  - Interactive Before & After image gallery slider.
  - Google Reviews carousel featuring verified 5.0-star customer testimonials.
  - Interactive FAQ accordion.
  - Estimate modal popup and on-page quote request form with photo upload dropzone.
- **Compliance:** Includes dedicated Privacy Policy and Terms of Service pages.
